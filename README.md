# Brainrot Heist

A Steal-a-Brainrot-style 3D game for the make.fun Roblox brainrot
competition (`roblox-brainrot-01`). Built with **Rojo on Linux, no Roblox
Studio** — every part, character and script is generated from
`default.project.json` + the Luau sources under `src/`.

## The game

- **Conveyor**: brainrots spawn at the cyan portal and walk a 300-stud
  conveyor from west to east. 12 characters across 6 rarities, from
  Noobini Pizzanini ($25, $1/s) to Giraffa Celeste ($250,000, $10,000/s).
  Gold (2x, 10%), Diamond (4x, 3%) and Rainbow (8x, 1%) mutations.
- **Bases**: 8 player bases (30x30, colored, lockable door, 8 slots each).
  Touch a brainrot on the conveyor to buy it; it walks to your base and
  earns cash every second.
- **Steal**: touch a rival's brainrot to carry it off. They can slap you
  with the Slap tool to make you drop it, or lock their base for 30s.
  A stolen brainrot returns home after 45s if it is not placed.
- **Rebirth**: $10K / $100K / $1M / $10M / $100M for x2 / x4 / x8 / x16 / x32
  income multipliers.
- **HUD**: cash, income per second, brainrot count, How to Play, Lock Base
  and Rebirth buttons, toast notifications.

## Build

```sh
rojo build default.project.json --output game.rbxl
```

(Or `~/workspace/makefun/roblox-tools/rojo build ...` with the bundled
Rojo 7.7.1 binary.)

The place is generated by `~/workspace/makefun/roblox-tools/gen_project.py`
— edit the generator, not the 16,000-line `default.project.json`, if you
change the world.

## Publish (George's click)

This entry is **not published yet**. To finish it:

1. Create a public GitHub repo and push this folder (the kit and the
   build tools live outside it at `~/workspace/makefun/roblox-brainrot-kit/`
   and `~/workspace/makefun/roblox-tools/`).
2. In Roblox Studio (or Creator Dashboard), create a public place from
   `game.rbxl`, upload an icon and a thumbnail — the first thumbnail must
   be one of the screenshots above.
3. Fill in `PLAY.json` with the real place link and ids:
   `{"url": "https://www.roblox.com/games/<placeId>", "place_id": <placeId>, "universe_id": <universeId>}`
   (the zeros in there now are a placeholder; the gate refuses them).
4. Run the kit's record command for the sealed session recordings.
5. Submit with the kit CLI: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.

## Files

- `game.rbxl` — the built place (703 instances, 555 parts, 7 scripts)
- `src/` — Luau: `shared/BrainrotData.luau`, `server/Main.server.luau` +
  `server/modules/` (BaseManager, Economy, Spawner, StealSystem),
  `client/HUD.client.luau`
- `main.ts` — the kit hand-in program (adapted from the starter)
- `screenshots/` — the 4 renders above
- `PLAY.json`, `TOUR.json` — place link and the tour definition
- `vendor/makefun-roblox.ts` — kit vendor file, unchanged
